# Политика конфиденциальности «Машиномира»

Одна страница — `index.html`. Публикуется через GitHub Pages, адрес
указывается в App Store Connect и внутри приложения.

Почему отдельный репозиторий, а не рядом с флагомировским: в адресе
политики не должно стоять имя чужой игры — проверяющий Apple открывает
ссылку и видит, чья это страница.

Русский и английский на одной странице: адрес один, а витрина App Store
показывает его во всех странах.

Правки — прямо в `index.html`, дату внизу менять вместе с текстом.
